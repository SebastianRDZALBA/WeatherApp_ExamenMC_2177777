Sistema IoT que adquiera variables ambientales mediante un ESP32 y un sensor BMP280. El BMP280 proporciona, altitud, temperatura y presión atmosférica. El sistema almacena las lecturas en Google Firebase Realtime Database y las manda a una aplicación web adaptable a computadoras y smartphones.
